# Divar Real Estate Data Analysis

A data cleaning, validation, normalization, and analysis project for **Divar real estate advertisements in Iran**.

The project processes raw real estate advertisement data and prepares a clean and validated dataset for further statistical analysis, market analysis, and Power BI dashboards.

---

## ⚙️ Requirements

Before running the project, make sure you have:

* Python 3.10 or higher
* pip
* Git (if cloning the repository)

It is recommended to use a Python virtual environment.

---

## 🚀 Installation

### 1. Clone the Repository

Clone the project and navigate to the project directory:

```bash
git clone <repository-url>
cd <project-folder>
```

---

### 2. Create a Virtual Environment

On Windows:

```bash
python -m venv .venv
```

Activate the virtual environment:

```bash
.venv\Scripts\activate
```

On macOS/Linux:

```bash
source .venv/bin/activate
```

---

### 3. Install Required Packages

All required Python packages are listed in `requirements.txt`.

Install them using:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

After installing all required packages, run the main execution file:

```bash
python Notebooks/run_all.py
```

`run_all.py` is responsible for running the project pipeline in the correct order.

You do **not** need to run the individual processing scripts manually.
